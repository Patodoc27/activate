# Activate — registro de calificaciones STV

PWA de calificaciones: el docente carga actividades (con plazo máximo) y notas; familias y estudiantes las ven en tiempo real.

- `index.html` + `js/` + `styles.css` — la app (PWA instalable, Android/iPhone/PC)
- `db/` — esquema, reglas de privacidad (RLS) y seed para Supabase
- Backend: Supabase (Postgres + Auth + Realtime). Hosting: GitHub Pages.

Demo: `docente.demo@activate.stv` / `familia.demo@activate.stv` / `estudiante.demo@activate.stv` — clave `Activate2026`
